# 变更记录

一个需要独立验收或跨会话的需求一篇，放在本目录，命名 `YYYY-MM-DD-<主题>.md`。写完在[文档地图](../../README.md)的“正在进行的变更”里登记；完成后把当前行为并入对应 Design，本文档标“已合并”并冻结。

## 骨架

```markdown
# <主题>：<一句话>

> 状态：实现中 · 更新：YYYY-MM-DD
> 最近变化：<结论变化 1–3 条>
> 要你决定：<无 / 1–3 条，各带推荐>

## 业务目的
## 支持场景
## 排除场景
## 不变量
## 失败约定
## 验收依据
## 当前状态与证据
## 还没定
```

## 规则

- 六点每点 1–3 句，写结论，不写讨论过程。
- 只在跨会话、需要独立验收或涉及多模块时创建；小改动直接改 Design 的“最近变化”。
- 完成后把当前行为并入对应 Design，本文档标“已合并到 X”并冻结，不再随代码更新。
- 放弃时标“放弃”，写原因和留下的状态。
